# 0001. 回線を選べる年の範囲の決め方

- 状態: 採用
- 日付: 2026-11-22

## 背景

回線（`packages/era-data/src/lines.ts` の `LINES`）は年ごとに選べるものが変わる。
選べ始める年は商用サービスの開始で決まるが、終わりの年は「サービスの終了」と「普及の終わり」のどちらでも決められる。
サービスの終了で決めると、ISDN のようにほとんど誰も新しく選ばなくなった回線が長く選択肢に残り、その年の雰囲気からずれる。

## 決定

`availableYears` の終わりの年は、新しくその回線を選ぶ人がほとんどいなくなった年にする。
サービスが続いていても、普及の統計や当時の報道で新規の契約がほぼなくなったと分かる年で打ち切る。
根拠は各行の `sources` に書く。

## 結果

- 選択肢がその年に実際に選ばれていた回線に近づく
- 終わりの年は統計の読み方に幅があるため、`sources` の根拠と合わせて見直す
